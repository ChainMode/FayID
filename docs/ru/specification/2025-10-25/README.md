# Спецификация протокола FayID 1.0

FayID — протокол суверенной идентичности и подотчётности (по модели владения ключом `Holder-of-Key`) для экосистемы iFay. Не опираясь на централизованные удостоверяющие центры (CA) или провайдеров идентичности (IdP), FayID непередаваемо связывает каждую индивидуальную цифровую персону (`iFay`) по схеме «один ко многим» с уникальным **Человеком-прототипом** (`Human Prime`, `hid_`), а каждую цифровую сущность общей роли (`coFay`) напрямую, в рамках одноуровневого владения, привязывает к одному ответственному идентификатору `HumanID` (`hid_`) или `OrganizationID` (`org_`).

Этот каталог содержит русскоязычное издание **финальной спецификации FayID 1.0 (редакция `2025-10-25`)**. Все главы и нормативные положения взаимно однозначно соответствуют канонической спецификации на упрощённом китайском языке (`zh-CN`); в случае любых межъязыковых расхождений каноническим и авторитетным изданием выступает редакция `zh-CN`.
